# Design reference audit

Audit performed 18 November 2026. Only public pages were inspected; no account-only screens or proprietary assets were used.

## Luma: public home

`https://luma.com/home` exposes an Events home with Upcoming and Past views, a Discover Events entry point and sign-in. This supports the personal events → discovery workflow described in the brief. Dynamic event content was not rendered in the text-only browser view.

## Luma: discover

`https://luma.com/discover` visibly presents an introductory discovery message, popular events with cover imagery, category browsing, featured community calendars and local-city exploration. The page listed Ho Chi Minh City. UniPass borrows these information patterns—search, categories, event covers, location and organizer identity—using original Vietnamese copy and student-focused sample data.

## Luma help documentation

- Creating an event documents title, dates and timezone, in-person/online/hybrid format, cover, location, description, visibility and capacity, followed by management settings.
- Searching for events documents search, map, city/category discovery and personalized feeds, with public events discoverable and private events link-only.
- Adding hosts and managers documents co-host identity, manager access control and check-in staff as distinct permissions.

These are functional references, not copied screens or text.

## ERP 1C Academy dashboard

The URL `https://erp-1c-academy.vercel.app/dashboard` could not be opened with the available browser tool (reported inaccessible). Consequently, its live colors, font, stroke weights and exact composition were **not verified**. The direction implemented here uses only the prompt's stated design extrapolation: warm paper, high-contrast outlines, hard offset shadows, compact mono labels, bold display type, lime/lilac/coral accents and an asymmetrical hero. No ERP-specific course content or source assets are reproduced.

## Viewport audit and limits

The reference browser did not expose desktop/mobile screenshots or viewport controls. The local UI has responsive breakpoints at 850px and 620px and targets 360px mobile width. Visual screenshot QA remains pending until a browser preview is available.
